# IKCO Worker Voice — صدای کارگر ایران‌خودرو

سامانه ارتباط کارگران با نماینده کارگری — اندروید آفلاین‌محور + سرور سازمانی سبک.

- **رابط کاربری:** فارسی، راست‌چین کامل، فونت وزیرمتن، تاریخ شمسی، اعداد فارسی
- **کلاینت:** Java خالص روی API استاندارد اندروید (بدون هیچ وابستگی خارجی)، SQLite محلی
- **سرور:** تک‌فایل Python فقط با کتابخانه استاندارد، REST + توکن Bearer، SQLite
- **همگام‌سازی:** آفلاین‌محور (Outbox) — برنامه بدون سرور کامل کار می‌کند؛ با سرور، داده‌ها میان همه گوشی‌ها جریان می‌یابد
- **امنیت:** هش رمز SHA-256+Salt، رمزنگاری AES-256-GCM برای اطلاعات تماس، کنترل نقش در کلاینت و سرور، تاریخچه اجباری و عدم حذف پرونده‌ها

## ساختار ریپو

```
app/                     پروژه اندروید (اندروید ۶ به بالا — targetSdk 34)
  src/  res/  assets/    سورس، منابع و دیتابیس نمونه (demo.db)
server/                  سرور سازمانی + راهنمای استقرار (README-ONLINE.md)
  seed/demo.db           دیتابیس اولیه سرور (۱۰ کاربر، ۲۴ درخواست نمونه)
scripts/build_apk.sh     ساخت APK بدون Gradle (aapt2 + ecj + d8 + apksigner)
docs/screenshots/        تصاویر پیش‌نمایش صفحات
.github/workflows/       ساخت خودکار APK با هر push
```

## اجرای سریع

```bash
# ۱) سرور (اختیاری — بدون آن برنامه کاملاً محلی کار می‌کند)
cd server && python3 ikco_server.py --port 8080

# ۲) ساخت APK
bash scripts/build_apk.sh          # یا با Android Studio از پوشه app/
```

در برنامه: **تنظیمات ← سرور سازمانی ← آدرس سرور ← تست اتصال ← ورود مجدد**
سپس تغییرات هر دستگاه به‌صورت خودکار و صف‌محور همگام می‌شود.

## CI
